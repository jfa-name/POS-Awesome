1. **Inicio de sesión (Login):**

Para entrar en la plataforma, introducir:
• Usuario: correo electrónico del usuario.
• Contraseña: Asignada al usuario.

Escritorio:
En el escritorio se encuentran los accesos directos a:
• POSAwesome: Aplicación para crear notas de entregas y facturas de ventas.
• Lista Facturas de Ventas: Listado de facturas.
• Lista Notas de Entrega: Listado de albaranes.
• Apertura POS: Apertura de cajero.
• Cierre POS: Cierre de cajero.



---

**2. Procedimiento para la creación de Facturas de Venta**

En “MENÚ” pulsar sobre “Facturas de venta”


1. Seleccionar en MENU -> “Factura de Venta”:
2. Seleccionar Cliente:
3. Introducir artículos:

• Pulsar en “+” para añadir cantidades o “-” para eliminar.
• Pulsar “Papelera” para eliminar un producto de la selección.
• Elegir y comprobar el “Lote” correspondiente.

4. Pulsar PAGAR para proceder al pago.
5. Elegir “Forma de pago”
6. Introducir “Notas adicionales” si es necesario.
7. Finalizar:

   1. VALIDAR para guardar la factura (no imprime la factura).
   2. SUBMIT & PRINT Para Validar e imprimir la factura.
   3. CANCEL PAYMENT para cancelar el pago (no la factura) y volver a poder introducir o modificar productos.

**Nota:** Al pulsar SUBMIT & PRINT se abrirá una pestaña, donde se debe seleccionar la impresora correcta para imprimir la factura:

**Dependiendo del tamaño del documento, ésta operación puede tardar varios segundos.**

---



**3. Procedimiento para la emisión de Notas de Entrega**

Seleccionar en “MENU” -> “Nota de entrega”:

Seleccionar “Cliente”:

Introducir artículos:

• Pulsar en “+” para añadir cantidades o “-” para eliminar.
• También se puede añadir directamente en “QTY”, en la parte superior izquierda, la cantidad de productos.
• Pulsar “Papelera” para eliminar un producto de la selección.
• Elegir y comprobar el “Lote” correspondiente.

4. Pulsar “PROCEED” para proceder a la entrega.
5. Introducir “Firma” del cliente en la entrega:
6. Introducir “Notas adicionales” si es necesario.
7. Finalizar:

   1. VALIDAR para guardar el albarán (no imprime el albarán).
   2. SUBMIT & PRINT Para Validar e Imprimir el albarán.
   3. CANCEL DELIVERY NOTE para cancelar la entrega (no el albarán).

**8. Reglas para los lotes y emisión de lotes diferentes.**

Regla de Lotes:
1. Si el lote tiene "Fecha de expiración" se seleccionará el lote con la fecha más cercano a expirar.
2. Si el lote no tiene "Fecha de expiración" se seleccionará el lote con la primera fecha de manufacturación.
3. No se mostrará lotes si la "Fecha de expiración" está vencidas.
4. Se mostrará el producto con menos "Cantidad Actual"

**Los productos con lotes vencidos, indicarán la cantidad de stock disponible, pero no se podrá entregar o facturar lotes con fecha de expiración vencida.**

Ejemplo de producto con lote expirado:

**12. Consideraciones previas a tener en cuenta con el navegador web Chrome:**

• Marcar “Vista de ordenador”: Pulsar en la parte superior derecha, sobre los tres puntos y seleccionar “Vista ordenador”

**• Permitir ventanas emergentes pestañas**

**IMPORTANTE: Es necesario que esté activa esta característica para poder imprimir
Configuración → Configuración de sitios → Ventanas emergentes y redirecciones:**

- Comprobar en Excepciones:
  https://baygroup.cafesbay.com

Pulsar sobre el candado y comprobar que se permiten ventanas emergentes del sitio:

**• Desactivar Zoom:**
Si no se desea que se haga zoom cuando se pulsa sobre un campo de selección, se ha desmarcar la función “Forzar zoom”.

Configuración → Accesibilidad → Desmarcar “Forzar zoom”
